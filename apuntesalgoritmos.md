# **ALGORITMOS**

deben tener Presicion, Determinismo y Finitud

**Presicion**: los pasos deben ser claros y concisos

**Determinismo**: Dados los mismos datos de entrada, siempre produce el mismo resultado

**Finitud**: Debe terminar en un tiempo razonable y no caer en ciclos infnitos

## **ETAPAS DEL DISEÑO DE ALGORITMOS**

1. Analizar el problema
    Entradas: Datos que el algoritmo recibira

    Salidas: Resultados esperados que el algoritmo debe generar

    Reestricciones: Condiciones o limites que se deben cumplir

    Procesos: Operaciones necesarias para tranformar entradas en la salida

2. Diseño del Algoritmo
    Se debe desarollar un plan detallado para resolver el problema identificado
    se debe definir el paso logico necesario y las herramientas que se emplearan

3. verificar el algoritmos
     se comprueba que el diseño del algoritmo sea correcto y cumpla con los requisitos 
     plantedos

4. implementacion del codigo 
    pasar del diseño del codigo a un lenguaje de programacion especifico
    importante seleccionar un lenguaje que se adapte a los requerimientos del problema

5. pruebas y correcciones 
    evaluar la funcionalidad del codigo

## **MANERAS DE REPRENSENTAR UN ALGORITMO**

1. PSEUDOCODIGO
    REPRESENTACION DEL CODIGO EN GENERAL EN LENGUAJE DE PROGRAMACION

    Inicio
    Leer base, altura
    area = (base*altura)/2
    Mostrar area
    Fin

2. DIAGRAMAS DE FLUJO

    REPRESENTACION GRAFICA DE LAS OPERACIONES LOGICAS DEL ALGORITMO Utilizan un 
    conjunto de símbolos estándar como óvalos para representar inicio y fin, 
    rectángulos para procesos, y rombos para decisiones. 

    Esto permite visualizar de manera clara y secuencial el flujo de ejecución 
    del algoritmo, facilitando la comprensión y detección de errores.
